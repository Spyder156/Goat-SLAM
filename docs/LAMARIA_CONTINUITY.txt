The changes
-----------
- Carry mutually matched recent observations into map associations within each
  camera, retaining the existing geometric outlier checks and unique ownership.
- Recover using either calibrated lens, with correct pooled indices and rig pose.
- Traverse the intended temporal keyframe neighborhood without getting stuck.
- Permit mapping during the existing bounded, initialized-IMU recovery interval.
- Allow confident initialized-IMU recovery before the later BA2 refinement.
- Use the camera model for coarse loop projection on native fisheye pixels.
- Save inertial frame history against recent temporal keyframes; rebase affected
  history exactly before keyframe removal. Keep visual matching references and
  the optimization spanning tree unchanged.
- Wait for optimization workers before export and account for all retained atlas
  maps, every input timestamp, visual tracking, coasting, and resets separately.

No detector count, local-map ratio, search radius, triangulation gate or geometric
outlier threshold was relaxed. Calibration, input images and IMU corrections are
unchanged by these continuity repairs. No ground truth enters SLAM. Independent
map origins are never joined with an invented transform.

Limits and evidence
-------------------
Coverage is not accuracy. The final history trial has 9.142 m scale-1 SE3 ATE
over this roughly 2 km open route (previous continuous trial: 9.255 m). Large
final-only adjacent jumps fell from 115 to 2, and from 49 to 0 near 1804-1820 s.
The two remaining 0.53/0.60 m steps near 1823 s have correct reference chains
and accompany real local drift; they are still a limitation. One-second relative
translation RMSE is 3.52 cm versus 9.17 cm in the preceding continuous trial.
The old short production-baseline interval worsens from 1.238 to 1.767 m ATE;
the coverage gain must not be presented as improvement on every accuracy metric.
Zero coarse-loop projection calls occurred, so that fix gets no credit for this
trial's accuracy. Ground-truth measurements are post-estimation checks only.
